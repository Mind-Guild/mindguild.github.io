Practice builds a retrieval structure

The route is learned in advance. With repetition, moving from one locus to the next can become rapid and automatic, leaving attention available for the new scenes.

01 · Compress

Three cards become one scene

In a PAO system, the first card supplies a person, the second an action, and the third an object. A 52-card deck can therefore become 17 composite scenes, plus one remaining card.

02 · Locate

Order lives in the route

Each distinctive scene is bound to the next locus in a well-rehearsed palace. Traversing those locations provides an ordered set of retrieval cues.

03 · Reconstruct

Imagery becomes cards again

During recall, the athlete revisits the palace, retrieves each scene, and reverses the PAO mapping. The paper uses this interaction to examine complementary conscious and nonconscious learning systems.

Source paper

Representational Tenets for Memory Athletics

Kevin Schmidt and colleagues connect a champion memory athlete’s first-person account with the Simulated, Situated, and Structurally Coherent Qualia (S3Q) framework, then propose testable hypotheses about expertise, distinctiveness, modality, and flexible conscious representation.

This learning demo uses 12 cards and four loci to make the method explorable. It is not a cognitive test or a literal model of neural activity. Neural mechanisms and performance predictions are presented in the paper as hypotheses for future experimentation.
