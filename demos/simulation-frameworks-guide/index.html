Voyager is an agent

Comparing Voyager with MuJoCo compares an agent with a physics engine. Voyager reaches Minecraft through the Mineflayer bot library.

“Minecraft” needs its interface named

MineRL gives the agent pixels and keyboard-and-mouse control. Mineflayer gives text and code. They sit at opposite ends of the interface range.

“GridWorld” needs an implementation named

MiniGrid, DeepMind’s AI Safety Gridworlds and the JAX ports differ in observations, speed and upkeep.

NetHack and MiniHack share an engine

They differ in experimental control. The full game generates its own levels; MiniHack lets you write them.

Demo videos, ranked by what one viewing settles

For each environment, the question is whether a single video can tell you if the world can host the agent. Ranks favor videos that answer that fastest.

Not watched

I have not watched these videos. Both browsers disconnected before I could pull transcripts, so each rank rests on the title, channel, length, view count, upload age and the paper behind the video. The confidence label says how far that basis supports the rank.

A video ranks higher when it

  • shows the agent’s raw input, the frame or tensor it actually receives
  • shows the action interface, graded or discrete
  • shows a scene being built or changed in code
  • comes from the platform’s creators
  • shows an agent learning or acting
  • does all this in fewer minutes

The watch log under each video stays in your browser only. Use it to record what each video actually showed, so the next pass can skip what is settled.
